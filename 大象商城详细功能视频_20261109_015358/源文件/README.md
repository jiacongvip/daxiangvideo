# 大象商城详细功能视频 · 源文件说明

本目录与合集中 115 条正式 MP4 **一一对应**，便于修改文案、字幕、旁白节奏后重新生成画面。  
**不是**剪映 / Premiere / Final Cut 工程，而是 Python + Pillow 逐帧绘制 + ffmpeg 合成。

## 目录结构

- `插件/`、`核心功能/`：每条视频一个子文件夹，文件夹名与成片文件名（去掉 `.mp4`）一致
- `公共工具/`：可迁移渲染代码、字体、依赖说明
- `视频源文件映射.csv` / `.json`：115 条映射（功能 id、视频相对路径、源文件夹）

成片 MP4 仍在上级 `插件/`、`核心功能/` 目录，**未重复放入源文件夹**。

## 每个项目内通常包含

| 文件 | 作用 |
|---|---|
| `script.json` | 分镜、旁白、阶段名、强调色 |
| `完整旁白脚本.md` | 可读旁白全文 |
| `重点字幕.srt` / `完整旁白字幕.srt` | 重点字幕与完整旁白字幕 |
| `时间轴.json` | 章节与字幕起止时间（与配音对齐） |
| `中文旁白.wav` | 整段旁白 |
| `原创低音量音乐.wav` / `旁白音乐混音.wav` | 背景乐与成片音轨 |
| `audio/00.mp3` 等 | 逐句 TTS 与边界（改旁白时用） |
| `封面.jpg` | 封面帧 |
| `QA.json` / `项目说明.json` | 生产校验摘要与批次提示 |

## 如何修改并重生成

1. **只改画面文案/阶段标题**：编辑 `script.json` 中 `heading`/`role`/`points`（慎改 `narration` 除非同步改配音），保留 `时间轴.json`，在 `公共工具` 下执行：
   ```bash
   python render_one.py ../插件/某项目文件夹
   ```
2. **改旁白文字**：改 `script.json` 的 `narration`，用 edge-tts 重做对应 `audio/NN.mp3`（需联网），再自行对齐生成新的 `时间轴.json` 与 `中文旁白.wav`（生产环境原流程见 `公共工具/run_series_reference.py` 的 `speech`/`align`），最后 `render_one.py`。
3. **改字幕用词但不改时长**：可直接改 `.srt`；若只重出画面，当前入口仍以 `时间轴.json` 的字幕为准，请同步改 `时间轴.json` 里 `subtitles` 文本。
4. **重新合成背景乐**：`python render_one.py <项目> --remake-music`

输出成片写在该项目文件夹内（`script.json` 的 `output_filename`）。请自行核对后，再替换上级正式合集中的同名 MP4（替换前建议备份）。
