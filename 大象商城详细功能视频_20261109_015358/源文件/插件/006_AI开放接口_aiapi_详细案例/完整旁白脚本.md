# 大象商城｜AI开放接口

## 1. 让AI调用有边界
角色：授权管理员 / 对接方
旁白：这里是大象商城。AI开放接口面向有授权的技术对接，把商品、订单和运营操作放到统一网关。用虚构的商品维护流程讲清楚：先确认能做什么，再发起调用，不能把AI理解成不受权限限制的管理员。
重点字幕要点：统一入口；先授权；再执行操作
内部来源（不进客户片）：aiapi_README.md:3,34-45

## 2. 两道权限，不越权
角色：站点管理员
旁白：调用使用令牌鉴权，权限跟随站点管理员，并受到令牌范围约束。先列出当前令牌可用操作，再选择需要的动作。管理端有接口说明、令牌管理和调用日志；令牌可创建、启停和撤销。
重点字幕要点：管理员权限；Token范围；操作发现
内部来源（不进客户片）：aiapi_README.md:3-11,38,64-65,111-117

## 3. 商品，从分类到库存
角色：授权商品运营
旁白：商品维护包括分类查询、新增、修改与状态设置；商品可以查询列表和详情、新增、修改、设置状态以及调整库存。多规格商品创建时，还可以传入各规格的价格和库存。
重点字幕要点：分类管理；商品增改上下架；库存调整
内部来源（不进客户片）：aiapi_README.md:39-40,68-85

## 4. 订单动作，有明确边界
角色：授权订单管理
旁白：订单侧支持列表、详情、备注、快递发货，以及关闭未支付订单。退款申请接口只提供查询列表和详情，不包含审核打款。
重点字幕要点：列表 / 详情；备注 / 快递发货；关闭未支付订单
内部来源（不进客户片）：aiapi_README.md:41-42

## 5. 会员、统计与上传
角色：授权运营人员
旁白：会员操作包含列表、详情、等级查询和调整等级，也列有积分、余额、佣金调整。此类修改涉及账户，应严格限制授权范围。统计提供概览和商品排行，图片上传支持链接或图片数据，不等于自动获得所有媒体权限。
重点字幕要点：等级 / 积分 / 余额；概览 / 商品排行；图片上传
内部来源（不进客户片）：aiapi_README.md:43-45

## 6. 试调用、错误与日志
角色：授权对接方
旁白：这里提供试运行参数示例，也区分未授权、无权限、未知操作、限流和业务错误。对接时先看操作清单，再核对参数和返回结果，必要时查调用日志。
重点字幕要点：支持试运行参数；权限 / 限流错误；调用日志
内部来源（不进客户片）：aiapi_README.md:20-32,58-65,117

## 7. 插件扩展，先发现再调用
角色：授权技术对接方
旁白：其他插件可以按接入规范，声明自己开放的操作。对接时先从可用操作清单发现能力，再选择需要的动作。统一入口不等于所有插件自动全开放，具体能调用什么，仍由权限与令牌范围共同决定。
重点字幕要点：插件独立声明；发现可用操作；按权限调用
内部来源（不进客户片）：aiapi_README.md:38,47

## 8. 统一入口，按权限协作
角色：大象商城 · 产品流程回顾
旁白：从发现可用操作，到商品与订单维护，再到会员、统计和上传，AI开放接口把调用组织在统一入口里。管理员控制授权，对接方遵循操作范围，让技术连接与业务职责对应起来。
重点字幕要点：发现操作；授权调用；日志与管理
