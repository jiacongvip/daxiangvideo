# 大象商城｜代理充值升级

## 1. 先签约，再充值升级
角色：申请人 / 平台财务
旁白：这里是大象商城。代理充值升级，把申请、电子签约、充值与会员等级衔接在一起。
重点字幕要点：申请升级；电子签约；充值与升级
内部来源（不进客户片）：agentrecharge_README.md:5

## 2. 先配置等级与区间
角色：平台管理方
旁白：平台先按会员等级设置充值区间，明确最低和最高充值金额。申请人选择升级路径前，应当了解目标等级的条件。
重点字幕要点：按等级配置；最低充值额；最高充值额
内部来源（不进客户片）：agentrecharge_README.md:10

## 3. 签约是否必需，可配置
角色：申请人 / 平台
旁白：充值之前可以对接法大大电子签约。是否要求签约由配置决定。流程先判断是否需要签约，需要时先完成签约，再继续充值。
重点字幕要点：申请；法大大电子签约；配置是否需要
内部来源（不进客户片）：agentrecharge_README.md:5,13

## 4. 线上走收银台
角色：申请人
旁白：线上充值使用已有收银台，例如微信支付。申请人在收银台完成充值，后续升级以充值到账为条件。
重点字幕要点：选择线上充值；已有收银台；到账后升级
内部来源（不进客户片）：agentrecharge_README.md:11,14

## 5. 线下先交凭证，再审核
角色：申请人 / 财务
旁白：线下充值不是上传图片就算到账。功能包括银行卡或二维码转账，申请人提交凭证后，由后台财务审核。
重点字幕要点：银行卡或二维码；提交凭证；后台财务审核
内部来源（不进客户片）：agentrecharge_README.md:12

## 6. 赠送规则与升级条件分开看
角色：平台 / 会员
旁白：充值赠送包括余额和积分，两者按照各自可配置倍数计算。充值到账后，功能支持自动升级会员等级。
重点字幕要点：余额赠送倍数；积分赠送倍数；到账后自动升级
内部来源（不进客户片）：agentrecharge_README.md:9,14

## 7. 申请、签约、充值、升级
角色：大象商城 · 产品流程回顾
旁白：申请人完成申请与所需签约，选择线上或线下充值；平台设置等级区间，财务核实线下凭证，再衔接到账后的等级升级。把申请人和管理方的操作分清楚，就是代理充值升级的完整使用路径。
重点字幕要点：申请与签约；充值与审核；到账后升级
