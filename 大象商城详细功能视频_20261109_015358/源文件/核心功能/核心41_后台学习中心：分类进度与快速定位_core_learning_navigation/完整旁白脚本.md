# 大象商城 · 后台学习中心：分类进度与快速定位

## 从导航找到要看的使用项目
这里是大象商城。后台使用者学习商城操作时，可以在学习中心打开快速导航，先按分类看项目和完成情况，再跳到需要查看的位置。这个案例介绍后台使用导航，不把它说成面对消费者的独立课程交易或考试产品。

## 从顶部打开分类和项目导航
点击顶部快速导航按钮，右侧展开导航抽屉，主体按分类组织项目。抽屉打开时，背景页面暂停滚动，让用户先在当前列表里选择目标。打开导航是在查找位置，不会因为点开一个分类就自动完成里面的学习项目。

## 分类进度与项目状态分别查看
每个分类显示分类名称以及已完成和总数，项目列表显示项目标题、状态图标与已完成或未完成徽章。使用者可以先看分类整体情况，再找到其中待查看的项目。分类进度与某个项目的状态是不同层次的信息，查看导航本身并不改变这些记录。

## 点项目，关闭抽屉并定位高亮
选择一个项目后，抽屉关闭，页面滚动到对应位置，并短暂高亮目标项目。用户从列表选择回到正文位置，可以继续查看相关内容；完成一项后，再次打开导航寻找下一项。这里讲的是快速定位与状态查看，不承诺自动完成学习或提升考试成绩。

## 需要退出时有多种关闭方式
不需要跳转时，可以使用关闭按钮、点击遮罩层，或者按键盘上的ESC键关闭抽屉，关闭后恢复页面滚动。大象商城后台学习中心，从分类进度查看到项目定位，把较长的使用说明组织成可回看的导航入口。
