# 大象商城｜会员足迹与浏览记录查看

## 1. 从一个会员，回看浏览过程
角色：后台运营
旁白：这里是大象商城。会员足迹帮助运营人员围绕一个会员查看浏览记录。先从会员列表找到对象，再进入足迹，按内容类型、关键词和时间回看，不把一次浏览直接说成购买意向或成交。
重点：会员列表；足迹入口；筛选与查看
内部证据：core_足迹开发总结.md:6-17,25-29

## 2. 会员列表里，找到足迹入口
角色：后台运营
旁白：在会员列表的更多操作中，点击足迹，打开这个会员的浏览记录。进入后，页面显示当前查看会员的昵称和编号，记录按该会员筛选。先确认查看对象，再继续找具体记录，避免把不同会员的信息混在一起。
重点：找到目标会员；更多 → 足迹；查看会员昵称与ID
内部证据：core_足迹开发总结.md:10-17,25-29

## 3. 不同内容，按类型分开看
角色：后台运营
旁白：统一浏览记录可以容纳商品、文章、视频、课程、论坛帖子、店铺、活动和自定义页面等内容类型。已经接入统一记录的页面，按对应类型归类，运营人员再选择需要查看的类型。
重点：商品 / 文章；视频 / 课程；店铺 / 活动等
内部证据：core_统一浏览记录.md:3-14;core_足迹开发总结.md:4,14

## 4. 按类型、标题和时间缩小范围
角色：后台运营
旁白：记录较多时，按内容类型、标题关键词和时间范围进一步筛选。比如先选择商品类型，再找某个标题相关的记录，并限定时间范围。这样查看的是一组明确条件下的浏览记录，而不是在所有历史中反复翻找。
重点：内容类型；标题关键词；时间范围
内部证据：core_足迹开发总结.md:27-29

## 5. 看清记录，靠标题与缩略图
角色：后台运营
旁白：记录中包含标题、页面路径、缩略图和来源等信息，帮助辨认浏览的是哪个内容。每次浏览独立记录，可以按历史顺序回看。同样的商品再次出现，并不等于新增了一件商品，更不等于已经下单。
重点：标题与缩略图；页面与来源；每次浏览独立记录
内部证据：core_统一浏览记录.md:46-54;core_足迹开发总结.md:7,9,16

## 6. 次数与时长，各自有含义
角色：后台运营
旁白：浏览次数和浏览时长是不同的记录字段。次数用于了解浏览记录中的访问情况，时长用于回看停留信息。它们不是订单金额、付款状态或成交数量，不用浏览数据替代真实交易结果。
重点：浏览次数字段；浏览时长字段；不等于交易结果
内部证据：core_统一浏览记录.md:46-54;core_足迹开发总结.md:4,8-9

## 7. 找对会员，筛选后回看
角色：大象商城 · 足迹管理
旁白：从会员列表进入足迹，确认当前会员，再按类型、标题与时间筛选，最后结合标题、缩略图、来源和时间信息回看历史。会员足迹把这些查看动作组织在一起，让运营人员知道自己正在看哪一段浏览记录。
重点：会员入口；筛选记录；查看浏览历史
