## 字幕（成片_v5_字幕.mp4）
- 脚本 `_build/mk_ass_v4.py` → `_build/sub_v4.ass`，26 条，ASS 烧录（`-vf ass=...`）。
- 样式：`Heiti SC` / 72px / Bold / 描边 5 / 阴影 2 / Alignment=2 / MarginV=462（字幕底线约 1440，留出抖音底部 UI）。**macOS 上 libass 认 "Heiti SC" 这个名字，能直接找到 STHeiti。**
- 双行切分规则：每行 ≤12 字，按语义断；关键数字用金色高亮 `{\c&H6ED6FF&}`（RGB 255,214,110 → BGR 6ED6FF）。
- 每句尾 `end = 下一句 start - 0.02`，避免两条字幕同屏；进出加 `{\fad(60,60)}`。
- 校验方式：抽帧看 2s（数字人段）、20s（图1段）、33.5s（金色高亮）、45.5s（浅灰段），字幕在深浅底上都清楚。
